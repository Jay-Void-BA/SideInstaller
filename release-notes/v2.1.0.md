## SideInstaller v2.1.0

这是 Jay-Void-BA 维护的修改版，基于 FrizzleM/SideInstaller。

- Minis 安装步骤失败后可以点击 **Retry step** 重试，保留已完成步骤、下载和签名结果。
- Minis 页面支持从“文件”选择本地 IPA，检查文件后导入安装；终端支持 `--ipa` 路径。
- SideInstaller 首页增加“从文件安装”，成功导入后自动选择自定义 IPA。
- 移除 SideInstaller 启动时的软件更新检测和更新提示。
- 修复安装和 IPA 导入同时启动时的状态冲突。

### 下载与安装

- `SideInstaller.ipa`：未签名的 iOS 应用，需自行签名，或使用下面的 Minis 安装器安装。
- `siboot-aarch64`：供 Open Minis 使用的 ARM64 musl 静态安装器，包含重试和本地 IPA 功能。
- `install-minis.sh`：下载并校验本次 Release 的 Minis 安装器；默认安装本次 Release 的 IPA。
- `retry-local-ipa.patch`：Minis 源码修改补丁，基于 siboot `82b808d`。
- `SHA256SUMS`：下载文件的 SHA-256 校验值。

在 Open Minis 终端运行：

```sh
wget -qO- https://github.com/Jay-Void-BA/SideInstaller/releases/download/v2.1.0/install-minis.sh | sh
```

本地安装仅跳过 IPA 下载；签名仍需 Apple 账户、网络连接和有效的设备配对。
本 Release 未使用企业证书签名，未执行真机端到端安装测试。
