# SideInstaller repository instructions

## README updates

- Update `README.md` and `README.zh-CN.md` with every change. Explain what changed and update the relevant usage, setup, or development guidance. Keep the English and Simplified Chinese guides in sync.
- Update the affected component's README when it has one. For internal changes, document the relevant implementation, maintenance, or verification details.
- Sync the root guides in `patches/siboot/retry-local-ipa.patch` when editing them. Links from the prepared source to the parent checkout go through `SideInstaller/`. Check that the patch applies and that the documented links, commands, and version references match the change.
